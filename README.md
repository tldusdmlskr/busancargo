# 부산신항 배후도로 물류교통 혼잡 분석 프로젝트

부산신항의 수출입 물동량과 배후도로 교통 데이터를 결합해 현재 교통 병목구간을 찾고,
향후 물동량 증가 시 혼잡 위험이 커질 구간을 예측하는 프로젝트입니다.

## 프로젝트 개요

- **분석 대상**: 부산신항 배후도로 (신항남로, 가락대로, 녹산산업대로 등)
- **핵심 질문**: 부산신항 수출입 물동량과 배후도로 교통상황 사이에 어떤 관계가 있으며,
  어느 구간이 가장 취약한가?
- 자세한 배경/목적/분석흐름은 `기획서` 폴더 참고

## 폴더 구조
.
├── collect_all.py # LINK + AVI API 통합 수집 스크립트
├── .github/workflows/collect.yml # 자동 수집 GitHub Actions 워크플로
├── collected_data/ # 수집된 원본 CSV 저장 위치 (자동 커밋됨)
│ ├── link_traffic_all_YYYYMMDD_HHMM.csv
│ └── avi_traffic_all_YYYYMMDD_HHMM.csv
└── README.md

## 데이터 수집 자동화 안내

### 무엇을 수집하나
- **LINK 통행정보** (`BusanITSLINKTraffic`): 부산시 전체 도로 링크의 통행속도(spd)·교통량(vol),
  약 9,175건 (92페이지)
- **AVI 지점 교통량** (`BusanITSAVI`): 고속도로 IC/램프 지점 교통량, 약 70여 건 (1페이지)

**필터링 없이 전체 데이터를 그대로 저장**합니다. 어떤 구간을 최종 분석에 쓸지는
아직 확정 전이라, 나중에 필요한 lkId/지점만 코드 레벨에서 골라 쓰는 방식입니다.

### 수집 스케줄
날짜: 2026-07-29 ~ 2026-08-04 (7일간)
시간: 매일 07, 08, 09, 12, 17, 18, 19, 21시 (KST 기준)

### 왜 자동화가 필요한가 (중요)
이 API들은 **실시간 스냅샷 API**로, 조회 시점의 현재 데이터만 반환하고
**과거 시점을 지정해서 조회하는 기능이 없습니다.** 즉:
- 정해진 시각에 정확히 호출해야만 그 시점 데이터를 얻을 수 있음
- 한 번 놓친 시간대는 **영구적으로 복구 불가능**

이 때문에 팀원 개인 컴퓨터에 의존하지 않고, GitHub Actions로
**매시간 자동 실행**되도록 구성했습니다 (팀원 컴퓨터가 꺼져 있어도 문제없음).

### API 트래픽 한도 이슈와 해결
LINK API는 92페이지를 호출해야 하는데, 개발계정 트래픽 한도가 하루 500회라
하루 8개 시간대를 전부 돌리면 (92×8=736회) 한도를 초과합니다.
→ **팀원 4명의 서비스키를 시간대별로 분산 배정**해서 해결했습니다:

| 시간대 | 담당 키 |
|---|---|
| 07, 17시 | SERVICE_KEY_1 |
| 08, 18시 | SERVICE_KEY_2 |
| 09, 19시 | SERVICE_KEY_3 |
| 12, 21시 | SERVICE_KEY_4 |

키 1개당 하루 약 186회 호출 → 500회 한도 내 여유 있음.

### 서비스키 등록 방법 (신규 팀원 온보딩용)
1. 공공데이터포털(data.go.kr)에서 아래 두 API 각각 활용신청:
   - BusanITSLINKTraffic (LINKTrafficList)
   - BusanITSAVI (AVIList)
2. 발급받은 서비스키(Encoding 버전)를 레포 Settings → Secrets and variables → Actions
   에서 `SERVICE_KEY_1`~`SERVICE_KEY_4` 중 비어있는 자리에 등록
3. 코드 수정 필요 없음 — GitHub Actions가 자동으로 환경변수에서 읽어서 사용

### 자동 실행 확인 방법
레포 상단 **Actions** 탭 → 워크플로 실행 로그 확인 가능
(수집 대상 시각이 아니면 API 호출 없이 "스킵" 로그만 남기고 종료됨)

### 수동으로 한 번 실행해보고 싶을 때
Actions 탭 → 워크플로 선택 → **Run workflow** 버튼으로 즉시 실행 가능
(단, `check_collection_slot()`이 현재 시각 기준으로 대상 시간대인지 판단하므로
대상 시간대가 아니면 데이터 없이 종료됩니다)

### 데이터 받아보기 (팀원 전체)
```bash
git pull
```
`collected_data/` 폴더에 새로 쌓인 CSV가 로컬로 받아집니다.
