## 1. 지금까지 흐름 요약

```
① 상관분석(1단계)          물동량과 도로 통행량이 "같은 날" 같은 방향으로 움직이는가?  → 1차 스크리닝
② 시차분석(2단계)          물동량 변화가 며칠 뒤 도로에 반영되는가? (lag 0~14 탐색)     → 최적 lag 구간 확정
③ 회귀분석(3단계, 지금 할 것)  최적 lag를 반영한 상태에서 "통행량 1대 변화 → 물동량 몇 톤" 정량화
```

- 상관분석에서 서컨-제1배후도로 4개 구간이 가장 뚜렷했고(|r| 0.22~0.51), 나머지는 약함.
- 시차분석에서 lag=7·14 배수로 값이 크게 나온 게 요일 가짜상관이 아니라 실제 신호로 확인됨 → **요일효과 제거가 회귀분석 설계에 반드시 반영되어야 함**.
- 서컨은 제1배후도로 4개(전부 lag5) + 신항선 3개(대청-진해 lag7, 남진례-대청 lag7, 진해-남문대교 lag13)를 채택.
- 북컨/남컨은 상관·시차분석을 거쳐도 관계가 약함(R² 0.03~0.05) → 회귀분석은 "관계가 약하다는 걸 정량적으로 확인하는" 목적이 큼.

## 2. 이번 회귀분석에서 해야 할 것

### 2.1 요일효과 처리 — 두 버전을 같이 본다

| | 버전 A (편차값 회귀) | 버전 B (원본단위 + 요일더미) |
|---|---|---|
| y, X | 요일별 평균을 뺀 편차값 | 원본값 그대로 |
| 요일효과 | 사전에 제거 | 회귀식 안에 더미변수(월요일 기준)로 포함 |
| 계수 해석 | 요일 대비 편차끼리의 관계(원 단위 아님) | "통행량 1대 늘면 물동량 몇 톤"(원 단위 그대로 해석 가능) |
| 용도 | 도로-물동량의 순수 관계만 보고 싶을 때 | 원 단위 해석 + 요일 패턴도 같이 보고 싶을 때 |

두 버전의 R²가 거의 같으면(강건성 확인) 결론을 신뢰할 수 있고, 다르면 요일효과가 관계를 왜곡하고 있었다는 뜻이므로 반드시 같이 비교한다.

### 2.2 시차(lag) 반영 방법

물동량(t)이 도로에는 t+lag일에 반영된다고 보므로, 회귀식의 예측변수는

```
X(t) = 도로통행량(t + lag)
```

로 구성한다(=도로 컬럼을 lag만큼 "앞으로" 당겨서 물동량(t)과 같은 행에 배치). 각 조합의 lag은 시차분석(2단계) 결과값을 그대로 사용한다:

| 물동량 | 도로구간 | lag(일) |
|---|---|---|
| 서컨 | 남해선 북부산TG-김해JC | 5 |
| 서컨 | 남해2지선 가락IC-서부산TG | 5 |
| 서컨 | 중앙선 대동IC-초정IC | 5 |
| 서컨 | 남해선 김해JC-동김해IC | 5 |
| 서컨 | 부산신항선 대청IC-진해IC | 7 |
| 서컨 | 부산신항선 남진례IC-대청IC | 7 |
| 서컨 | 부산신항선 진해IC-남문대교 | 13 |
| 북컨 | 남해선 김해JC-동김해IC | 0 |
| 북컨 | 남해선 북부산TG-김해JC | 0 |
| 북컨 | 중앙선 대감JC-대동IC | 0 |
| 북컨 | 부산신항선 대청IC-진해IC | 1 |
| 남컨 | 남해2지선 가락IC-서부산TG | 0 |
| 남컨 | 중앙선 대동IC-초정IC | 10 |
| 남컨 | 부산신항선 진해IC-남문대교 | 0 |

※ 시차분석 결론(④): 최적시차는 "완만한 파동" 구간이라 "정확히 N일"보다 "구간"으로 서술하는 게 정직함. 위 표의 lag는 대표값이며, 코드에서는 ±2~3일 근방 lag도 함께 시도해 민감도를 확인하는 걸 권장.

### 2.3 다중공선성(VIF) 처리 — 최우선 미해결 과제

서컨 모델의 신항선 두 구간(`대청IC-진해IC`, `남진례IC-대청IC`)이 물리적으로 바로 이어진 구간이라 정보가 거의 중복됨 → VIF 15~47. 두 변수의 개별 계수(예: -0.59 vs +0.73)는 신뢰 불가하지만 모델 전체 R²는 유효함.

**해결 방법 (코드에 반영):**
1. VIF를 계산해 10을 넘는 변수 쌍을 자동 탐지
2. 두 변수를 평균으로 통합한 `신항선_대청진해_통합` 변수를 만들어 재적합
3. 원래 모델(두 변수 개별) vs 통합 모델의 R², AIC/BIC를 나란히 비교해 리포트에 실을 근거를 만든다

### 2.4 잔차진단

- Durbin-Watson (자기상관 — 일별 시계열이라 자기상관이 있을 가능성 높음, 있으면 "탄력성 크기는 유효하되 표준오차는 과소추정일 수 있음"으로 서술)
- Jarque-Bera (정규성)
- Breusch-Pagan (등분산성)
- 잔차 vs 적합값 산점도, Q-Q plot 이미지 저장

### 2.5 산출물

물동량별(서컨/북컨/남컨) × 버전(A/B) × 다중공선성 처리 여부로 총 결과 세트를 만들고, 기존 `RQ1_회귀분석_원본단위_요일더미_결과요약.csv`와 같은 형식(물동량, 변수, 계수, p-value, 유의, R2, Adj_R2, N)으로 저장한다. 여기에 VIF 열을 추가해 어떤 계수를 "개별 해석 가능"으로 볼지 바로 판단할 수 있게 한다.

## 3. 해석 시 주의사항 (보고서용)

- 상관계수·회귀계수 크기만으로 주 이동경로를 단정하지 않는다 — 방향(부호)이 물류 상식과 반대인 조합(서컨-남해선 등)은 계절성·경로분산·화물차비중 추정오차 등 다른 요인이 섞여있을 수 있음을 병기.
- 북컨/남컨은 도로 통행량보다 요일 자체(주말/평일 구조)가 물동량을 더 크게 설명 — "도로 데이터로 설명되는 부분은 작다"고 조심스럽게 서술.
- lag는 "정확히 N일"이 아니라 "N일 근방 구간"으로 서술.
- VIF가 높은 신항선 두 변수는 통합 변수 계수로만 해석하고, 개별 계수는 참고용으로만 제시.
