# RQ1. 서컨 회귀분석 데이터 오염 재확인 + 추가 발견 (긴급)

임노아님이 카톡에서 짚은 문제(서컨 7부두 개장 전 데이터가 실제로는 제외되지 않았을 가능성)를 회귀분석 코드/데이터에서 직접 확인했고, **실제로 회귀분석용 파일에도 같은 문제가 있었습니다.** 추가로 관련된 데이터 문제를 하나 더 발견해서 같이 정리합니다.

## 1. 확인 결과 — 개장 전 793일이 회귀분석에 그대로 포함되어 있었음

`RQ1_회귀분석용_서컨물동량.csv`(팀에서 "정제 완료"로 공유된 파일)를 직접 열어서 날짜별로 확인했습니다.

- 전체 1,166행 중 **793행이 2024-03-09(서컨 개장일) 이전**입니다. 실제 유효한 행은 373행뿐입니다.
- 이 파일의 `서컨물동량` 컬럼은 요일별 평균을 뺀 "편차값"인데, 개장 전 구간은 값이 -607 ~ -853 사이에서 거의 일정하게 나옵니다(표준편차 77). 이는 개장 전 실제 물동량이 쭉 0이었던 걸 그대로 요일평균 계산에 포함시켰기 때문입니다.
- **문제는 표본 수만 부풀려지는 게 아니라는 점입니다.** 개장 전 793일치 0이 요일별 평균 계산에 섞여 들어가면, 그 평균 자체가 실제보다 낮게 잡히고, 그 결과 **개장 이후(진짜 유효한 373일)의 편차값까지 함께 왜곡됩니다.** 즉 "정제됐다"고 알려진 파일은 유효 기간 데이터도 오염된 상태였습니다.
- 제가 이전에 이 파일을 "이미 정제된 파일"로 신뢰하고 그대로 사용해서 R²=0.494, N=1,166으로 보고드렸던 서컨 결과는 전부 이 오염의 영향을 받은 수치입니다. 정정합니다.

## 2. 코드 수정 및 재실행 결과

서컨물동량은 이제 어떤 파일을 쓰든 상관없이, 원본 wide table(`RQ1_wide_table.csv`)에서 2024-03-09 이전을 결측 처리한 뒤 다시 lag를 적용하도록 코드를 고쳤습니다. 재실행한 결과는 다음과 같습니다.

| | 이전(오염된 파일 사용) | 수정 후(개장 전 완전 제외) |
|---|---|---|
| N | 1,166 | **373** |
| 버전 A R² | 0.4918 | **0.1500** |
| 버전 B R² | 0.4936 | **0.1692** |

R²가 0.49에서 0.17로 크게 낮아졌습니다. 이전에 "서컨은 도로 통행량으로 절반 가까이 설명된다"고 봤던 결론은 상당 부분 이 오염(개장 전/후 물동량 수준 차이가 마치 도로 변수와 강하게 연관된 것처럼 보이게 만든 효과) 때문이었을 가능성이 큽니다.

## 3. 추가 발견 — 남해선 북부산TG-김해JC 구간, 2023-12-04 이후 데이터 없음

수정한 코드에 "이 모형 표본에서 특정 변수가 거의 다 0이면 자동으로 경고" 기능을 추가했는데, 바로 이 문제가 걸렸습니다.

- `남해선(순천-부산)_북부산TG-김해JC` 구간은 **2023-12-04 이후로 값이 전부 0 또는 NaN**입니다. 즉 서컨의 유효 분석기간(2024-03-09~) 전체에서 이 도로구간은 데이터가 하나도 없습니다.
- 이 변수가 들어간 서컨 모형에서 이 변수의 계수가 사실상 0에 수렴하는데, VIF·표준오차 계산이 불안정해지면서(거의 상수 컬럼이라) `RuntimeWarning`까지 발생했습니다.
- **이 구간은 상관분석(1단계) 결과에서 서컨물동량과 가장 강한 상관(r = -0.5063, 전체 30개 조합 중 1위)으로 보고됐던 바로 그 구간입니다.** 상관분석에 쓰인 물동량_상관분석용.csv가 이 회귀분석용 wide table과 같은 방식으로 만들어졌다면, 이 -0.5063이라는 강한 상관 자체도 "서컨 개장 전엔 도로 데이터가 있었는데 물동량은 0이었고, 개장 후엔 도로 데이터가 끊겼는데 물동량만 있는" 구조적 우연 때문일 가능성이 있습니다. **상관분석 결과 중 이 조합(서컨-남해선 북부산TG-김해JC)은 별도로 재검토가 필요합니다.**
- 북컨 모형에도 같은 변수가 들어가 있지만(lag0), 북컨은 분석기간이 2022년부터라 이 구간의 데이터 단절 이전 기록이 많이 남아 있어 문제가 덜합니다. 서컨만 유효기간 전체가 이 변수의 결측 구간과 겹치는 게 문제입니다.
- 참고로 같은 서컨 모형의 `중앙선_대동IC-초정IC` 구간도 유효기간(2024-03-09~2026-07) 중 앞쪽 약 20개월은 데이터가 비어 있고 2025-11-18 이후 8개월치만 실제 값이 있습니다. 자동경고 기준(0이 아닌 값 5% 미만)에는 안 걸렸지만(12.9%), 표본이 최근 8개월에 쏠려 있다는 점은 해석 시 참고할 필요가 있습니다.

## 4. 코드에 추가한 자동 점검 기능

`run_lag_regression.py`에 데이터 커버리지 자동 점검 단계를 추가했습니다. 각 모형에 실제로 들어가는 표본 안에서, 설명변수마다 "0이 아닌 값의 비율"을 계산해서 5% 미만이면 자동으로 경고를 출력하고 결과 파일에도 표시합니다. 이번처럼 특정 구간의 데이터 수집이 끊긴 걸 놓치지 않기 위한 장치입니다. 결과는 `RQ1_변수별_데이터커버리지.csv`에 저장됩니다.

## 5. 정리 — 다음에 확인해야 할 것

1. **상관분석(1단계) 결과 재검토** — 특히 서컨-남해선 북부산TG-김해JC 조합(1위로 보고된 조합)이 이 데이터 단절 때문에 생긴 가짜 상관인지 확인 필요. `물동량_상관분석용.csv`의 서컨 처리 방식과 이 구간의 실제 데이터 커버리지를 함께 봐야 합니다.
2. **서컨 회귀분석 결과 전면 수정** — R²가 0.49가 아니라 0.17 수준이라는 점, 신항선 두 구간의 다중공선성은 표본이 줄어들며 VIF가 오히려 더 심해졌다는 점(17→290) 모두 보고서에 반영이 필요합니다.
3. 시차분석(2단계) 결과 중 서컨 관련 부분도, 어떤 데이터로 lag를 탐색했는지에 따라 같은 오염 문제가 있었는지 확인해볼 필요가 있습니다.

수정한 코드와 재실행 결과를 같이 첨부합니다.
